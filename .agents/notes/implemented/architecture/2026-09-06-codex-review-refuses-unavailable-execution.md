# Codex review preserves unavailable execution as unavailable

H07 extends the optional runtime with signed frozen review policy, exact trusted
Git shadows and strict local finding/receipt validation. It deliberately cannot
mint independent-review evidence on this host. `AGENTS.md`, `DECISIONS.md`
MIGRATION-01, `docs/quality-document.md`, `bin/ARCHITECTURE.md` and the runtime
boundary review govern this implementation: capability-dependent acceptance
cannot be replaced by a fixture PASS.

The existing approval verifier and actual source/dependency hashes constrain
policy; opaque handles preserve binding ownership. A fixed trusted Git helper
copies exact objects without source/global configuration, hooks, filters,
credentials, replace refs or network fetch. Output locations resolve against
that target. Supplied execution receipts remain untrusted even when their fields
match, because no real host-supervised session occurred.

Unavailable containment is checked before spending objective budget. Charging a
review that never starts would make missing infrastructure exhaust approved work.
A future supported launch must use H06's existing spending mechanism immediately
before execution and keep accounting separate from authenticated receipts.

No sandbox service, generic runner, provider marketplace, dependency or fallback
to uncontained execution is introduced. We give up actual review/counterexample
execution here; diagnostic fixtures cannot accept this adapter or a release.
Revisit only when an authorized host supplies supported containment and real
independent execution. The precise API and H08 boundary live in
`packs/autonomy/repo-template/scripts/quality-orchestrator/contracts-review-v1.md`.
