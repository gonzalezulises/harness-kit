# Reuse scoped decisions without accepting new artifacts

Under AGENTS.md, DECISIONS.md MIGRATION-01 and docs/quality-document.md,
continuation extends the existing local runtime, signature verifier, journal and
closed capabilities. A signed human gate binds the original accepted baseline,
AC, defect class, rule and full identity/registry invariants. The runtime verifies
durable changed-representation cases and semantic counterexamples itself, then
creates opaque per-operation permission. Candidate booleans and generic regression
callbacks cannot substitute for those checks.

Signed category and total limits become immutable objective journal data.
Reservations and standalone attempts consume them before work; fresh runs and
revocations retain the original accounting. No default maxima were invented:
operators and signed approved authority must agree on the total, and all category
values must be explicitly approved. A reusable permission never accepts newly
generated artifact bytes. Historical signature checks share the existing verifier
and preserve original receipt bytes without treating expired grants as current.

A workflow engine, external service, second signature mechanism and automatic
approval signing were rejected because these requirements fit the current runtime.
The cost is deliberately narrow proof support: ordinary record representation and
registered source/digest effects only. Budget accounting does not certify product
tests or independent review; missing execution/containment stays blocked. Revisit
this boundary only when another closed capability and its real execution evidence
are explicitly approved. The versioned contract is
`packs/autonomy/repo-template/scripts/quality-orchestrator/contracts-continuation-v1.md`.
