# Decisions

Long-form architectural decision records. Short ones stay in the root `DECISIONS.md`;
anything needing more than a few paragraphs — with context, options weighed, and
consequences — gets a file here.

Naming: `NNNN-short-slug.md`, e.g. `0001-postgres-over-sqlite.md`.

A useful record answers: what forced the decision, what was rejected and why, and what
becomes harder because of it. A record that only states the outcome tells the next session
nothing it could not read from the code.
