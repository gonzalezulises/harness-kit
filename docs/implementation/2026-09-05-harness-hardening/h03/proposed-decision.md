## Proposed append-only H03 decision for the controller

H03 implements one opt-in nested Node package with pinned YAML2.9.0/Zod4.5.4,
strict typed identity and per-runtime opaque handles. The host supplies repository,
approved runtime/schema contract, exact authority digest, enrolled Ed25519 keys,
current time/revocation basis and file classes. Adoption and baseline receipts
bind exact scoped authority and recomputed input manifests. No candidate boolean,
callback or deserialized summary creates authority. Exact numeric source forms
remain distinct; comments, unsupported schemas and unknown proofs stop. Closed
canonical reorder and source-content SHA256 derivation produce assessments only;
postconditions and execution permissions remain unavailable. This deliberately
limits initial schemas and preserves legacy minimal/full portability. See the
H03 Agent Note and packs/autonomy/index.md. Implementation does not adopt a
policy, accept a baseline, enroll owner keys or grant production authority.
